Cobra Kai

Alunos:
Arleane dos Santos Moraes, Isadora Assis, Claudio Josimar.

Sobre o projeto:

O Cobra Kai é um jogo da cobrinha que desenvolvemos em grupo para a disciplina de JavaScript do curso de Análise e Desenvolvimento de Sistemas do Senac.
Escolhemos esse jogo porque queríamos trabalhar com algo divertido e que permitisse colocar em prática o que estamos aprendendo nas aulas.
Nossa ideia foi criar uma versão diferente do jogo tradicional da cobrinha, acrescentando um visual próprio, pontuação, ranking e alguns efeitos para deixar a experiência mais interessante.

Objetivo:
Nosso objetivo foi desenvolver um jogo interativo utilizando HTML, CSS e JavaScript.
O jogador precisa informar seu nome para começar a partida e controlar a cobrinha pelas setas do teclado. Durante o jogo, precisa pegar os alimentos que aparecem na tela para ganhar pontos e fazer a cobrinha crescer.
O desafio é conseguir a maior pontuação possível sem bater nas paredes ou no próprio corpo.

Tecnologias utilizadas:
Para desenvolver o projeto, utilizamos:
HTML: para criar a estrutura da página e organizar os elementos do jogo.
CSS: para trabalhar as cores, o posicionamento dos elementos e o visual da página.
JavaScript: para controlar os movimentos da cobrinha, a pontuação, as colisões e as funcionalidades do jogo.
VS Code: para desenvolver e editar nossos códigos.
Git e GitHub: para organizar o projeto, registrar as alterações e compartilhar o desenvolvimento entre os integrantes do grupo.

Funcionalidades:
Durante o desenvolvimento, conseguimos implementar:
Campo para informar o nome do jogador.
Botões para começar e reiniciar o jogo.
Movimentação da cobrinha pelas setas do teclado.
Alimentos que aparecem em posições aleatórias.
Pontuações diferentes para cada alimento.
Crescimento da cobrinha ao pegar os alimentos.
Aumento gradual da velocidade durante a partida.
Identificação de colisões com as paredes e com o próprio corpo.
Mensagem de fim de jogo com a pontuação alcançada.
Ranking dos jogadores.
Tabuleiro quadriculado com cores verdes.
Fundo com efeito de chuva neon.
Também começamos a trabalhar em uma nova aparência para a cobrinha, buscando deixar o personagem mais divertido e com uma identidade própria.

Como executar o projeto:
Para executar nosso jogo, basta seguir estes passos:
Baixar os arquivos do repositório.
Abrir a pasta do projeto no VS Code.
Abrir o arquivo index.html no navegador ou utilizar a extensão Live Server.
Digitar o nome do jogador.
Clicar no botão de começar.
Utilizar as setas do teclado para movimentar a cobrinha.
O jogo funciona diretamente no navegador, sem necessidade de instalar outros programas para jogar.

Organização do projeto:
Organizamos o projeto separando a estrutura da página, os estilos e as funcionalidades em arquivos diferentes.
O HTML contém os elementos da tela, o CSS é responsável pela aparência e o JavaScript controla o funcionamento do jogo.
Também utilizamos um arquivo JavaScript separado para o efeito de chuva neon do fundo.
Essa organização facilitou o desenvolvimento e as alterações feitas pelo grupo.

Melhorias que pretendemos fazer:
Ainda queremos continuar melhorando nosso jogo.
Entre as ideias estão aperfeiçoar o desenho da cobrinha, deixar os movimentos mais naturais e acrescentar novos detalhes visuais.
Conforme formos aprendendo mais sobre JavaScript, pretendemos aplicar esses conhecimentos no projeto.

Desenvolvimento em grupo:
Desenvolvemos o Cobra Kai em equipe, utilizando o GitHub para compartilhar os arquivos e acompanhar as atualizações.
Durante o processo, fizemos testes, corrigimos erros e alteramos algumas partes do código até chegar ao resultado que queríamos.
Também aprendemos mais sobre como trabalhar no mesmo projeto, organizar os arquivos e registrar nossas alterações por meio dos commits.
O projeto ainda pode receber melhorias, mas já conseguimos colocar em prática vários conteúdos que estudamos durante as aulas.

Considerações finais:
Com o desenvolvimento do Cobra Kai, conseguimos entender melhor como HTML, CSS e JavaScript trabalham juntos.
Além da programação, também tivemos a oportunidade de praticar o trabalho em equipe e a utilização do GitHub.
Nosso objetivo é continuar evoluindo o jogo e melhorar cada vez mais o que já desenvolvemos.
